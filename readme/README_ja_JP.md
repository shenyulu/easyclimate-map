## 🤗 easyclimate-mapとは？

easyclimate-map は、[easyclimate](https://github.com/shenyulu/easyclimate) 用の地図データを容易に取得するために設計されています。

>   🚨 **本パッケージは急速な開発進行中** 🚨
>
>   全てのAPI（関数/クラス/インターフェース）は変更される可能性があります。設計思想の更新や新機能追加に伴い、後方互換性のない変更が発生する場合があります。完成版ではないため、利用には注意が必要です。

## 😯 インストール方法

Pythonパッケージ管理ツール[pip](https://pip.pypa.io/en/stable/getting-started/)を使用してインストール可能です：

```
pip install easyclimate-map
```

関連する依存関係については、[インストールガイド](https://easyclimate-map.readthedocs.io/en/latest/install.html) を参照してください。

## 🪐 法的通知

本ソフトウェアを使用することにより、[法的通知](https://easyclimate-map.readthedocs.io/en/latest/legal.html) に記載された条件に同意したものとみなされます。
